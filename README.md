### FROM THE WORKSHOP

Everything below lives in [webapp-workbench](https://github.com/tonyarcher/webapp-workbench),
an npm-workspaces monorepo of small TypeScript apps behind one nginx gateway:

| Project | What it is |
|---|---|
| [rss-reader](https://github.com/tonyarcher/webapp-workbench/tree/main/apps/rss-reader) | Self-hosted RSS reader — Postgres-backed API, staggered feed poller with conditional GETs, Lit + TanStack Query frontend |
| [stock-game](https://github.com/tonyarcher/webapp-workbench/tree/main/apps/stock-game) | Paper-trading simulator — TanStack Start SPA, SQLite ledger, scheduled/backdated fills |
| [baseball-tracker](https://github.com/tonyarcher/webapp-workbench/tree/main/apps/baseball) | Baseball scorekeeping app built on Lit web components |
| [vertical-scroll-core](https://github.com/tonyarcher/webapp-workbench/tree/main/packages/vertical-scroll-core) | Reusable TikTok-style vertical feed engine (snap paging, embed players) |
| [tiktok-scroll](https://github.com/tonyarcher/webapp-workbench/tree/main/apps/tiktok-scroll) | Import a list of TikTok links and scroll them distraction-free |
| [lemmy-vertical-scroll](https://github.com/tonyarcher/webapp-workbench/tree/main/apps/lemmy-vertical-scroll) | Vertical-feed client for Lemmy |
